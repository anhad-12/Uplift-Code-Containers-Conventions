# bob_sessions

Required deliverable: IBM Bob task session summary screenshots (PNG) from **every** team member.

How: Bob IDE chat > Tasks > select a task > click the task header to open the session consumption summary > screenshot.

Name: `uplift_<A|B|C>_task<NN>_<slug>_summary.png`, for example `uplift_B_task07_proof_runner_summary.png`.
Log every one in `LOG.md`. Take the screenshot right after the task, not at the end.
